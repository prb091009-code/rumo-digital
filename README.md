# Site da Rumo Digital

Site estático publicado pelo GitHub Pages: https://prb091009-code.github.io/rumo-digital/

- Formulário de contato envia para o Sistema de Agentes (Google Apps Script), com validação e proteção contra spam.
- Google Analytics só carrega depois do aceite de cookies (LGPD). Para ligar, coloque o ID G-XXXX em `GA_ID` no `site.js`.
- Nenhuma chave secreta fica neste repositório.
